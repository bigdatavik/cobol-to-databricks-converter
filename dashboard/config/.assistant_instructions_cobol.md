## 🚨 CRITICAL: OUTPUT FORMAT RULES (READ THIS FIRST!)

### When User Selects "PySpark Notebook":
- Use PySpark DataFrame API: `df.withColumn()`, `F.when()`, `df.filter()`, `df.groupBy()`
- Import: `from pyspark.sql import functions as F`
- Use PySpark syntax for ALL transformations

### When User Selects "SQL via spark.sql()":
**🚨 TRUE HYBRID MODE: Smart Mix of spark.sql() + PySpark DataFrame API 🚨**

**HYBRID = Use SQL where safe, use PySpark where SQL would cause errors**

**Decision Tree:**

✅ **USE spark.sql() FOR (SAFE):**
1. Simple SELECT with explicit columns (no *, col pattern)
2. Filtering with WHERE (no derived columns)
3. Simple aggregations (GROUP BY without adding columns)
4. JOINs without column transformations
5. Creating TEMP VIEWS for simple queries

❌ **USE df.withColumn() FOR (RISKY):**
1. SELECT *, <new columns> ← Causes COLUMN_ALREADY_EXISTS
2. Adding derived columns to existing data
3. Multiple CASE WHEN statements adding columns
4. Transforming existing column values
5. Any pattern that might create duplicate column names

**REQUIRED IMPORTS:**
- ✅ `from pyspark.sql import functions as F` (ALWAYS)
- ✅ `from pyspark.sql import Window` (ALWAYS)

**TRUE HYBRID EXAMPLE:**

```python
from pyspark.sql import functions as F
from pyspark.sql import Window

# ✅ SAFE: Use spark.sql() for simple SELECT
df = spark.sql(f"""
    SELECT auth_id, member_id, status, approval_date, request_date
    FROM {SOURCE_CATALOG}.analytics_gold.prior_auth_summary
    WHERE auth_id IS NOT NULL
""")

# ✅ SAFE: Use df.withColumn() for adding/transforming columns
df = df.withColumn("turnaround_days",
    F.when(F.col("approval_date").isNotNull(),
           F.datediff(F.col("approval_date"), F.col("request_date"))
    ).otherwise(None)
)

df = df.withColumn("category",
    F.when(F.col("turnaround_days") <= 3, "FAST")
     .when(F.col("turnaround_days") <= 7, "STANDARD")
     .otherwise("SLOW")
)

# Write result
df.write.mode("overwrite").saveAsTable(f"{TARGET_CATALOG}.prior_auth_reports.turnaround_summary")
```

## 🔤 COBOL LANGUAGE ELEMENT CONVERSIONS

### 1. DATA DIVISION → PySpark Schema

**COBOL Picture Clauses → PySpark Types:**

| COBOL PIC | Description | PySpark Type |
|-----------|-------------|--------------|
| `PIC 9(n)` | Numeric integer | `IntegerType()` (n≤9), `LongType()` (n>9) |
| `PIC 9(n)V99` | Numeric with 2 decimals | `DecimalType(n+2, 2)` |
| `PIC S9(n)` | Signed integer | `IntegerType()` or `LongType()` |
| `PIC X(n)` | Alphanumeric | `StringType()` |
| `PIC A(n)` | Alphabetic | `StringType()` |
| `PIC 9(8)` (date) | Date as YYYYMMDD | `DateType()` or `StringType()` |
| `COMP` | Binary | `IntegerType()` or `LongType()` |
| `COMP-3` | Packed decimal | `DecimalType(p,s)` |

**Example Conversion:**

```cobol
* COBOL Working Storage
01  MEMBER-RECORD.
    05  MEMBER-ID            PIC 9(10).
    05  FIRST-NAME           PIC X(20).
    05  LAST-NAME            PIC X(30).
    05  DATE-OF-BIRTH        PIC 9(8).
    05  PREMIUM-AMOUNT       PIC 9(7)V99.
    05  ENROLLMENT-FLAG      PIC X(1).
    05  RAF-SCORE            PIC 9(1)V9999.
```

→

```python
from pyspark.sql.types import *

# Define schema for COBOL record layout
member_schema = StructType([
    StructField("member_id", LongType(), False),      # PIC 9(10)
    StructField("first_name", StringType(), True),    # PIC X(20)
    StructField("last_name", StringType(), True),     # PIC X(30)
    StructField("date_of_birth", DateType(), True),   # PIC 9(8)
    StructField("premium_amount", DecimalType(9,2), True),  # PIC 9(7)V99
    StructField("enrollment_flag", StringType(), True),     # PIC X(1)
    StructField("raf_score", DecimalType(5,4), True)  # PIC 9(1)V9999
])

# Read from Delta table (mainframe data loaded to lakehouse)
```

## 🔬 COMPLEX COBOL PATTERNS

### 1. Nested PERFORMs → Window Functions

```cobol
* COBOL nested loops
PERFORM OUTER-PARA
    VARYING YEAR-IDX FROM 2020 BY 1 UNTIL YEAR-IDX > 2024.

OUTER-PARA.
    PERFORM INNER-PARA
        VARYING MONTH-IDX FROM 1 BY 1 UNTIL MONTH-IDX > 12.

INNER-PARA.
    COMPUTE MONTHLY-REVENUE(YEAR-IDX, MONTH-IDX) = 
        CLAIMS-COUNT(YEAR-IDX, MONTH-IDX) * AVG-CLAIM-AMT.
```

→

```python
from pyspark.sql.window import Window

# Generate year-month combinations (cross join)
years_df = spark.range(2020, 2025).select(F.col("id").alias("year"))
months_df = spark.range(1, 13).select(F.col("id").alias("month"))
year_month_df = years_df.crossJoin(months_df)

# Join with data and calculate
result_df = year_month_df.join(
    claims_df,
    (year_month_df.year == claims_df.claim_year) &
    (year_month_df.month == claims_df.claim_month),
    "left"
).groupBy("year", "month").agg(
    (F.count("claim_id") * F.avg("claim_amount")).alias("monthly_revenue")
)

# Running totals with window functions
window_spec = Window.partitionBy("year").orderBy("month")
result_df = result_df.withColumn("running_total",
    F.sum("monthly_revenue").over(window_spec)
)
```

### 1. HEDIS Measure Calculation

```cobol
IDENTIFICATION DIVISION.
PROGRAM-ID. HEDIS-BCS-CALC.

DATA DIVISION.
WORKING-STORAGE SECTION.
01  WS-MEASURE-YEAR     PIC 9(4) VALUE 2023.
01  WS-MIN-AGE          PIC 99 VALUE 50.
01  WS-MAX-AGE          PIC 99 VALUE 74.
01  WS-DENOMINATOR      PIC 9(7) VALUE ZERO.
01  WS-NUMERATOR        PIC 9(7) VALUE ZERO.
01  WS-COMPLIANCE-RATE  PIC 9(3)V99.

PROCEDURE DIVISION.
MAIN-LOGIC.
    PERFORM READ-MEMBERS
    PERFORM CALC-DENOMINATOR
    PERFORM CALC-NUMERATOR
    PERFORM CALC-RATE
    PERFORM WRITE-REPORT
    STOP RUN.

CALC-DENOMINATOR.
    * Count eligible women (ages 50-74)
    SELECT COUNT(*)
    INTO WS-DENOMINATOR
    FROM MEMBERS
    WHERE GENDER = 'F'
    AND AGE BETWEEN WS-MIN-AGE AND WS-MAX-AGE
    AND ENROLLMENT-STATUS = 'ACTIVE'.

CALC-NUMERATOR.
    * Count members with mammogram
    SELECT COUNT(DISTINCT MEMBER-ID)
    INTO WS-NUMERATOR
    FROM CLAIMS
    WHERE PROCEDURE-CODE IN ('77065', '77066', '77067')
    AND SERVICE-YEAR = WS-MEASURE-YEAR
    AND MEMBER-ID IN (SELECT MEMBER-ID FROM ELIGIBLE-MEMBERS).

CALC-RATE.
    IF WS-DENOMINATOR > 0
        COMPUTE WS-COMPLIANCE-RATE = 
            (WS-NUMERATOR / WS-DENOMINATOR) * 100
    ELSE
        MOVE ZERO TO WS-COMPLIANCE-RATE
    END-IF.
```

→

```python
# HEDIS BCS Measure Calculation in PySpark
from pyspark.sql import functions as F

# Parameters (WORKING-STORAGE)
measure_year = 2023
min_age = 50
max_age = 74

# Read members (CALC-DENOMINATOR)
members_df = spark.table(f"{SOURCE_CATALOG}.analytics_gold.members")

denominator_df = members_df.filter(
    (F.col("gender") == "F") &
    (F.col("age") >= min_age) &
    (F.col("age") <= max_age) &
    (F.col("enrollment_status") == "ACTIVE")
)

# Add age groups for reporting
denominator_df = denominator_df.withColumn("age_group",
    F.when((F.col("age") >= 50) & (F.col("age") <= 59), "50-59")
     .when((F.col("age") >= 60) & (F.col("age") <= 69), "60-69")
     .when((F.col("age") >= 70) & (F.col("age") <= 74), "70-74")
     .otherwise("OTHER")
)

# Read claims and find numerator (CALC-NUMERATOR)
claims_df = spark.table(f"{SOURCE_CATALOG}.analytics_gold.claims")

mammogram_codes = ['77065', '77066', '77067']

numerator_df = claims_df.filter(
    (F.col("procedure_code").isin(mammogram_codes)) &
    (F.year(F.col("service_date")) == measure_year)
).select("member_id").distinct()

# Join to get members with screening
denominator_df = denominator_df.join(
    numerator_df,
    "member_id",
    "left"
).withColumn("had_mammogram",
    F.when(numerator_df.member_id.isNotNull(), True).otherwise(False)
)

# Calculate compliance rate by age group (CALC-RATE)
summary_df = denominator_df.groupBy("age_group").agg(
    F.count("*").alias("denominator"),
    F.sum(F.when(F.col("had_mammogram"), 1).otherwise(0)).alias("numerator")
).withColumn("compliance_rate",
    F.when(F.col("denominator") > 0,
           (F.col("numerator") / F.col("denominator")) * 100
    ).otherwise(0.0)
)

# Write report (WRITE-REPORT)
summary_df.write.mode("overwrite").saveAsTable(
    f"{TARGET_CATALOG}.hedis_reports.bcs_summary"
)

# Display results
display(summary_df.orderBy("age_group"))
```

### 2. Claims Adjudication

```cobol
IDENTIFICATION DIVISION.
PROGRAM-ID. CLAIM-ADJUDICATE.

PROCEDURE DIVISION.
    READ CLAIM-FILE.
    
    * Apply benefit limits
    IF CLAIM-AMOUNT > POLICY-LIMIT THEN
        COMPUTE PAID-AMOUNT = POLICY-LIMIT
        MOVE "PARTIAL" TO PAYMENT-STATUS
        COMPUTE DENIED-AMOUNT = CLAIM-AMOUNT - POLICY-LIMIT
    ELSE
        MOVE CLAIM-AMOUNT TO PAID-AMOUNT
        MOVE "FULL" TO PAYMENT-STATUS
        MOVE ZERO TO DENIED-AMOUNT
    END-IF.
    
    * Apply deductible
    IF DEDUCTIBLE-MET = "N" THEN
        IF PAID-AMOUNT > REMAINING-DEDUCTIBLE THEN
            SUBTRACT REMAINING-DEDUCTIBLE FROM PAID-AMOUNT
            MOVE "Y" TO DEDUCTIBLE-MET
        ELSE
            SUBTRACT PAID-AMOUNT FROM REMAINING-DEDUCTIBLE
            MOVE ZERO TO PAID-AMOUNT
        END-IF
    END-IF.
    
    * Apply coinsurance
    COMPUTE MEMBER-RESPONSIBILITY = PAID-AMOUNT * COINSURANCE-PCT.
    COMPUTE PLAN-PAYS = PAID-AMOUNT - MEMBER-RESPONSIBILITY.
```

→

```python
# Claims Adjudication in PySpark
claims_df = spark.table(f"{SOURCE_CATALOG}.analytics_gold.claims")
policies_df = spark.table(f"{SOURCE_CATALOG}.analytics_gold.policies")

# Join claims with policy data
adjudicated_df = claims_df.join(
    policies_df,
    claims_df.member_id == policies_df.member_id,
    "inner"
)

# Apply benefit limits
adjudicated_df = adjudicated_df.withColumn("paid_amount",
    F.when(F.col("claim_amount") > F.col("policy_limit"),
           F.col("policy_limit"))
     .otherwise(F.col("claim_amount"))
)

adjudicated_df = adjudicated_df.withColumn("payment_status",
    F.when(F.col("claim_amount") > F.col("policy_limit"), "PARTIAL")
     .otherwise("FULL")
)

adjudicated_df = adjudicated_df.withColumn("denied_amount",
    F.when(F.col("claim_amount") > F.col("policy_limit"),
           F.col("claim_amount") - F.col("policy_limit"))
     .otherwise(0.0)
)

# Apply deductible
adjudicated_df = adjudicated_df.withColumn("after_deductible",
    F.when(F.col("deductible_met") == "N",
        F.when(F.col("paid_amount") > F.col("remaining_deductible"),
               F.col("paid_amount") - F.col("remaining_deductible"))
         .otherwise(0.0)
    ).otherwise(F.col("paid_amount"))
)

# Apply coinsurance
adjudicated_df = adjudicated_df.withColumn("member_responsibility",
    F.col("after_deductible") * F.col("coinsurance_pct")
)

adjudicated_df = adjudicated_df.withColumn("plan_pays",
    F.col("after_deductible") - F.col("member_responsibility")
)

# Write adjudicated claims
adjudicated_df.write.mode("overwrite").saveAsTable(
    f"{TARGET_CATALOG}.claims_analysis.adjudicated_claims"
)
```

### 3. Risk Adjustment (RAF Scoring)

```cobol
IDENTIFICATION DIVISION.
PROGRAM-ID. RAF-CALC.

DATA DIVISION.
WORKING-STORAGE SECTION.
01  BASE-RAF-SCORE      PIC 9V9999 VALUE 1.0000.
01  AGE-FACTOR          PIC 9V9999.
01  HCC-FACTOR          PIC 9V9999.
01  TOTAL-RAF-SCORE     PIC 9V9999.

PROCEDURE DIVISION.
    * Get age factor
    EVALUATE TRUE
        WHEN AGE >= 85
            MOVE 1.5000 TO AGE-FACTOR
        WHEN AGE >= 75
            MOVE 1.3000 TO AGE-FACTOR
        WHEN AGE >= 65
            MOVE 1.1000 TO AGE-FACTOR
        WHEN OTHER
            MOVE 1.0000 TO AGE-FACTOR
    END-EVALUATE.
    
    * Add HCC (Hierarchical Condition Category) weights
    MOVE ZERO TO HCC-FACTOR.
    IF DIABETES-FLAG = "Y"
        ADD 0.3180 TO HCC-FACTOR
    END-IF.
    IF CHF-FLAG = "Y"  
        ADD 0.4190 TO HCC-FACTOR
    END-IF.
    IF COPD-FLAG = "Y"
        ADD 0.3280 TO HCC-FACTOR
    END-IF.
    
    * Calculate total RAF score
    COMPUTE TOTAL-RAF-SCORE = BASE-RAF-SCORE + AGE-FACTOR + HCC-FACTOR.
```

→

```python
# Risk Adjustment Factor (RAF) Scoring
members_df = spark.table(f"{SOURCE_CATALOG}.analytics_gold.members")
diagnoses_df = spark.table(f"{SOURCE_CATALOG}.analytics_gold.diagnoses")

# Base RAF score
members_df = members_df.withColumn("base_raf_score", F.lit(1.0000))

# Age factor
members_df = members_df.withColumn("age_factor",
    F.when(F.col("age") >= 85, 1.5000)
     .when(F.col("age") >= 75, 1.3000)
     .when(F.col("age") >= 65, 1.1000)
     .otherwise(1.0000)
)

# Get HCC flags from diagnoses
hcc_flags = diagnoses_df.groupBy("member_id").agg(
    F.max(F.when(F.col("hcc_code").isin(["HCC17", "HCC18", "HCC19"]), 1).otherwise(0)).alias("diabetes_flag"),
    F.max(F.when(F.col("hcc_code").isin(["HCC85"]), 1).otherwise(0)).alias("chf_flag"),
    F.max(F.when(F.col("hcc_code").isin(["HCC111", "HCC112"]), 1).otherwise(0)).alias("copd_flag")
)

# Join with members
raf_df = members_df.join(hcc_flags, "member_id", "left").fillna(0)

# Calculate HCC factor
raf_df = raf_df.withColumn("hcc_factor",
    (F.when(F.col("diabetes_flag") == 1, 0.3180).otherwise(0.0)) +
    (F.when(F.col("chf_flag") == 1, 0.4190).otherwise(0.0)) +
    (F.when(F.col("copd_flag") == 1, 0.3280).otherwise(0.0))
)

# Total RAF score
raf_df = raf_df.withColumn("total_raf_score",
    F.col("base_raf_score") + F.col("age_factor") + F.col("hcc_factor")
)

# Write RAF scores
raf_df.select("member_id", "age", "age_factor", "hcc_factor", "total_raf_score") \
    .write.mode("overwrite").saveAsTable(
        f"{TARGET_CATALOG}.risk_adjustment.member_raf_scores"
    )
```

```python
     .when((F.col("age") >= 60) & (F.col("age") <= 69), "60-69")
     .otherwise("70-74")
)

print(f"BCS Denominator: {denominator_df.count():,} eligible members")

# COMMAND ----------

# MAGIC %md
# MAGIC ## Step 2: Calculate Numerator

# COMMAND ----------

# Find members with mammogram claims
claims_df = spark.table(f"{SOURCE_CATALOG}.analytics_gold.claims")

mammogram_codes = ['77065', '77066', '77067']
measurement_year = 2023

numerator_members = claims_df.filter(
    (F.col("procedure_code").isin(mammogram_codes)) &
    (F.year(F.col("service_date")) == measurement_year)
).select("member_id").distinct()

print(f"Members with mammogram: {numerator_members.count():,}")

# COMMAND ----------

# MAGIC %md
# MAGIC ## Step 3: Calculate Compliance Rates

# COMMAND ----------

# Join denominator with numerator
result_df = denominator_df.join(
    numerator_members.withColumn("had_screening", F.lit(True)),
    "member_id",
    "left"
).fillna({"had_screening": False})

# Calculate rates by age group
summary_df = result_df.groupBy("age_group").agg(
    F.count("*").alias("denominator"),
    F.sum(F.when(F.col("had_screening"), 1).otherwise(0)).alias("numerator")
).withColumn("compliance_rate",
    F.round((F.col("numerator") / F.col("denominator")) * 100, 2)
)

# Write results
summary_df.write.mode("overwrite").saveAsTable(
    f"{TARGET_CATALOG}.hedis_reports.bcs_summary"
)

# Display summary
display(summary_df.orderBy("age_group"))

print(f"""

   Total Denominator: {result_df.count():,}
   Total Numerator: {result_df.filter(F.col("had_screening")).count():,}
   Overall Rate: {(result_df.filter(F.col("had_screening")).count() / result_df.count() * 100):.2f}%
   Results saved to: {TARGET_CATALOG}.hedis_reports.bcs_summary
""")
```

## 🔍 COMMON COBOL PITFALLS & SOLUTIONS

### 1. Implicit Decimal Points

**COBOL Issue:**
```cobol
01  PREMIUM-AMOUNT    PIC 9(5)V99.  * V = implied decimal
```

**Solution:**
```python
# Always use DecimalType with explicit precision and scale
from pyspark.sql.types import DecimalType

df = df.withColumn("premium_amount",
    F.col("premium_amount").cast(DecimalType(7, 2))
)
```

### 2. COMP/COMP-3 Fields

**COBOL Issue:**
```cobol
01  MEMBER-COUNT      PIC 9(7) COMP-3.  * Packed decimal
01  TRANSACTION-ID    PIC 9(10) COMP.   * Binary
```

**Solution:**
```python
# Map to appropriate numeric types
# COMP-3 → DecimalType or LongType
# COMP → IntegerType or LongType

df = df.withColumn("member_count", F.col("member_count").cast("long"))
df = df.withColumn("transaction_id", F.col("transaction_id").cast("long"))
```

### 3. Fixed-Length Records

**COBOL Issue:**
```cobol
* Fixed-width mainframe file
01  MEMBER-RECORD.
    05  MEMBER-ID        PIC X(10).  * Positions 1-10
    05  NAME             PIC X(40).  * Positions 11-50
    05  AMOUNT           PIC 9(7)V99. * Positions 51-59
```

**Solution:**
```python
# Read as text and parse positions
df = spark.read.text("/path/to/fixed_width.dat")

df = df.select(
    F.substring("value", 1, 10).alias("member_id"),
    F.trim(F.substring("value", 11, 40)).alias("name"),
    F.substring("value", 51, 9).cast(DecimalType(9,2)).alias("amount")
)
```

### 4. Leading Zeros

**COBOL Issue:**
```cobol
01  MEMBER-ID    PIC 9(10).  * Leading zeros preserved
* Value: 0000123456
```

**Solution:**
```python
# Store as string to preserve leading zeros
df = df.withColumn("member_id",
    F.lpad(F.col("member_id").cast("string"), 10, "0")
)

# Or use BIGINT if numeric operations needed
df = df.withColumn("member_id_numeric",
    F.col("member_id").cast("long")
)
```

## 📚 REFERENCE: COBOL-TO-PYSPARK QUICK LOOKUP

| COBOL Statement | PySpark Equivalent |
|----------------|-------------------|
| `MOVE A TO B` | `df.withColumn("B", F.col("A"))` |
| `ADD A TO B` | `df.withColumn("B", F.col("B") + F.col("A"))` |
| `SUBTRACT A FROM B` | `df.withColumn("B", F.col("B") - F.col("A"))` |
| `MULTIPLY A BY B` | `df.withColumn("result", F.col("A") * F.col("B"))` |
| `DIVIDE A BY B` | `df.withColumn("result", F.col("A") / F.col("B"))` |
| `IF A > B` | `F.when(F.col("A") > F.col("B"), ...)` |
| `PERFORM PARA` | Function call or inline code |
| `PERFORM VARYING` | `for` loop or window function |
| `STRING...INTO` | `F.concat()` or `F.concat_ws()` |
| `UNSTRING...INTO` | `F.split()` or `F.regexp_extract()` |
| `INSPECT...REPLACING` | `F.regexp_replace()` |
| `READ FILE` | `spark.table()` or `spark.read` |
| `WRITE RECORD` | `df.write.saveAsTable()` |
| `SORT` | `df.orderBy()` |
| `SEARCH` | `F.array_contains()` |
| `INITIALIZE` | `df.withColumn(..., F.lit(0))` |
