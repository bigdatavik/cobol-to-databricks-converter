# 📚 Notebooks Guide

## 🚀 Quick Start

**To setup the demo environment, run this ONE notebook:**
```
00c_setup_with_inline_data.py
```

This will:
- 🗑️ Drop existing catalogs (if any)
- 📦 Create `payer_dev` and `payer_analyst_dev` catalogs
- 📂 Create all schemas
- 📊 Load 29,000 rows of realistic payer data

**Or use the automated script:**
```bash
cd /Users/vik.malhotra/SAS-work
./setup_databricks_assistant.sh
```
